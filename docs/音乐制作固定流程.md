# 音乐制作固定流程

**FIXED PIPELINE v1.0** · 从一句话设想到可交付母带

> 基准样本：《旧日光 / THE LIGHT WE KEPT》 · NEON TIDE · 4:34 · 66 小节 · E♭ 大调 · 器乐
> 配套阅读：[音乐情感表达指南](reference/音乐情感表达指南.md)（写什么）、[自然感音色生成提示词](reference/自然感音色生成提示词.md)（怎么发声）
> 本文档回答第三个问题：**怎么把它做成能交付的文件。**

## 0. 这份文件"固定"什么

三句话：

1. **固定工序，不固定风格。** 十个阶段顺序不变；要跳阶段，必须在工程里留下记录和理由。
2. **每个阶段必须有实体产出。** 一张表、一段脚本、一个文件。没有产出的阶段不算完成。
3. **先定目标值，再定验收区间。** 不达标就回退，不靠"再听一遍"说服自己。

| 内容 | 状态 | 说明 |
|---|---|---|
| 阶段顺序与门禁 | **冻结** | 见第 1 节，跳过即视为未完成 |
| 验收阈值 | **冻结** | 见第 10 节；放宽阈值等于降低交付质量 |
| 参数基线 | 半冻结 | 可改，但须记录"改动值 / 理由 / 重测结果" |
| 题材、调性、编制、歌词 | 自由 | 由立项卡决定 |

适用范围：单曲、EP 曲目、纯器乐、带人声歌曲。差异集中在阶段 4（人声与歌词）与阶段 9（演唱交付），其余阶段一致。

## 1. 流程总览

```
[0 立项卡] → [1 情绪与结构] → [2 作曲] → [3 演奏] → [4 音色]
                                                          ↓
[9 交付] ← [8 验证] ← [7 母带] ← [6 混音] ← [5 工程实现]
```

| 阶段 | 只回答一个问题 | 必须产出 | 门禁（未过则退回） |
|---|---|---|---|
| 0 立项 | 这首歌要做什么、不要做什么 | 立项卡 12 字段 | 一句话设定可否证伪；避免项 ≥4 条 |
| 1 情绪与结构 | 情绪在第几秒转折 | 四维表 + 弧线句 + 结构时间线 | 高点唯一；至少一个"减法段落" |
| 2 作曲 | 主题凭什么被记住 | 动机细胞 + 变形登记表 + 和弦网格 | 动机 ≤7 音；每次重复只改一个维度 |
| 3 演奏 | 人是否在场 | 触键三层表 + tempo map + 微时序规则 | 力度联动 ≥3 个参数 |
| 4 音色 | 声音为什么可信 | 每件乐器一张参数卡 | 关掉混响仍可信；起音/持续/释放各有结构 |
| 5 工程 | 能否重跑出同一结果 | 单一真源脚本 + 固定种子 | 同种子两次渲染逐样本一致 |
| 6 混音 | 谁在前、谁在后、多远 | 通道表 + 发送表 + 段落增益表 | 主音干声占比 >60% |
| 7 母带 | 交出去会不会失真 | 目标值表 + 处理链 | LUFS / 真峰 / LRA 三项同时命中 |
| 8 验证 | 是不是真的做到了 | 四项测量 + 四问自检 | 指标在区间内，且无假声明 |
| 9 交付 | 别人能否直接用 | 格式矩阵 + 命名 + 文档 | 清单全勾 |

样本项目的实际耗时分布：作曲 25%、音色 25%、混音与母带 20%、验证与返工 20%、交付物（封面/文档/MIDI）10%。

> 这个分布值得记住：**四分之三的工作量在"作曲完成"之后。**

## 2. 阶段 0：立项卡

一张卡决定后面所有事。字段固定 12 项，缺一项不允许开始作曲。

| # | 字段 | 填法要求 | 样本（旧日光） |
|---|---|---|---|
| 1 | 一句话设定 | 必须写成"不是 A，而是 B"的形式 | 不是一首"悲伤"的曲子，而是一段被傍晚光线照亮的记忆 |
| 2 | 风格 | 两个标签以内 | 记忆小品 / Ambient Neoclassical |
| 3 | 调性 | 明确大调或小调，是否转调 | E♭ 大调，全曲不转调 |
| 4 | 速度 | 标称值 + 弹性范围 | 60 BPM（58–62 弹性，结尾 51） |
| 5 | 拍号 | — | 4/4 |
| 6 | 长度 | 先定小节数，再算时长 | 66 小节 ≈ 4:27 + 7 s 尾 = 4:34 |
| 7 | 情绪四维 | 每维给 0–1 的数值 | 效价 0.35 / 唤醒 0.30 / 紧张 0.35 / 距离 0.45 |
| 8 | 视角与场景 | 谁、对谁、在哪 | 第一人称独白，傍晚的旧房间，对一个不在场的人说话 |
| 9 | 克制程度 | 高度克制 / 逐渐外放 / 直接宣泄 | 高度克制，接近"想留住但知道留不住" |
| 10 | 核心音色 | ≤6 件，按主次排序 | 加弱音器中提琴、毛毡钢琴、音乐盒、弦乐、簧风琴、房间声 |
| 11 | 避免项 | ≥4 条，必须是具体反例 | 不要鼓组、不要爆发的强音、不要刺耳金属余响、不要把怀旧等同于噪点和低通 |
| 12 | 交付格式 | 采样率 / 位深 / 分发格式 | 48 kHz / 24-bit；WAV、FLAC、MP3 320、AAC 256、30 s 试听、MIDI |

三条硬规则：

- **时长由小节反算，不凭感觉。** 66 小节 × 4 拍 = 264 拍，平均约 59 BPM ≈ 4:27，加 7 s 房间尾音得 4:34。改速度就重算，不靠"大概四分钟"。
- **避免项要能判分。** "不要太俗"无法执行；"不要 EDM drop"可以。
- **一句话设定里必须有否定。** 只有"温暖、怀旧"的歌，最后都会写成同一种温暖、同一种怀旧。

## 3. 阶段 1：情绪与结构

### 3.1 四维表：整体基线 + 分段值

先给全曲基线，再给每段一个值。基线决定配器，分段值决定动态。

| 段落 | 效价 | 唤醒 | 紧张 | 距离 | 一句话 |
|---|---|---|---|---|---|
| Intro | 0.30 | 0.15 | 0.25 | 0.30 近 | 房间声与碎片，只给动机前三个音 |
| A1 | 0.40 | 0.28 | 0.32 | 0.40 | 主题第一次完整出现 |
| B | 0.50 | 0.40 | 0.42 | 0.55 打开 | 弦乐与簧风琴进入 |
| Climax | 0.45 | 0.55 | 0.50 | 0.60 | 音区最高，但不爆发 |
| A2 | 0.32 | 0.25 | 0.45 未竟 | 0.45 | 撤掉弦乐，主题回归 |
| Coda | 0.25 | 0.12 | 0.55 挂留 | 0.55 | 只剩碎片，未完全解决 |

**读法**：效价与唤醒可以升，**紧张度不必跟着音区一起升满**。样本高潮的紧张度 0.50 只比 B 段的 0.42 高一点，真正的未竟感留到 Coda 的 0.55——高点靠"打开"，结尾靠"没放下"。

（表中的分值是"逐段给值"这一方法的量化示意，用来逼自己把形容词换成可比较的数字；原始创作手记只有文字描述，没有这组数值。）

### 3.2 弧线句

用固定句式写，不许写形容词堆叠：

> 从【安静独白】开始，经过【主题出现、回忆变暖】，短暂到达【弦乐打开空间的高点】但不爆发，最终以【主动撤掉弦乐与低频、未完全解决的挂留】结束。

转折必须对应一个**可听见的事件**，写进表里：

| 时间 | 转折 | 可听事件 |
|---|---|---|
| 0:33 | 主题进入 | 中提琴第一次完整奏出五音动机 |
| 1:37 | 空间打开 | 弦乐 + 簧风琴进入，音区上移 |
| 2:24 | 高点 | 旋律到 B♭5，弦乐高音与低音钢琴加入，仍无鼓组 |
| 3:11 | 回落（减法） | 弦乐与簧风琴完全撤走 |
| 4:01 | 消散 | 只剩动机碎片 |
| 4:27 | 交还空间 | 房间声与混响尾音 |

### 3.3 结构时间线

固定列：段落 / 小节 / 时间 / 功能 / 编制增减。

| 段落 | 小节 | 时间 | 功能 | 编制 |
|---|---|---|---|---|
| Intro | 1–8 | 0:00–0:33 | 建立空间，只给动机碎片 | 房间声 + 钢琴 |
| A1 | 9–24 | 0:33–1:37 | 主题陈述两次 | + 中提琴；1:05 后音乐盒 |
| B | 25–36 | 1:37–2:24 | 打开，音区上升 | + 弦乐 + 簧风琴 |
| Climax | 37–48 | 2:24–3:11 | 唯一高点 | 全编制，仍无鼓 |
| A2 | 49–60 | 3:11–4:01 | 减法回归 | − 弦乐 − 簧风琴 |
| Coda | 61–66 | 4:01–4:27 | 未解决收束 | 钢琴 + 音乐盒残响 |
| Tail | — | 4:27–4:34 | 房间尾音 | 仅空间 |

三条结构规则：

1. **高点只有一个。** 样本的高潮只比 B 段响 1.3 dB——高点靠音区、密度与和声，不靠响度。若你的高潮比前段响 4 dB 以上，先怀疑是不是只会调音量。
2. **高点前必须有减法。** A2 撤掉弦乐与簧风琴，让最后一次主题暴露。没有减法的高点，只是持续堆叠的中段。
3. **结束状态在立项卡里已经写明。** 解决、未解决、消退，三选一，不许写完再决定。

## 4. 阶段 2：作曲

### 4.1 动机细胞

规则：**≤7 个音，含一个跳进 + 一次级进回落**。跳进给记忆点，级进给"没说完"。

样本动机 `B♭ – E♭ – G – F – E♭`，在 E♭ 大调中是 **5–1–3–2–1**：先向上四级，再级进回落，像一句停在半空的话。

再写第二句之前，先问：**这五个音换成任何音色，还认得出吗？** 认不出就不是动机，是音阶练习。

### 4.2 变形登记表

同一个动机出现四次，每次只改一个维度，并登记改了什么、保留了什么。

| 出现 | 位置 | 改什么 | 保留什么 | 情绪效果 |
|---|---|---|---|---|
| 1 | Intro | 只取前三个音，时值拉长 | 音程轮廓 | 尚未认出的熟悉感 |
| 2 | A1 | 句尾停在 F（A♭maj7 的 13 音） | 节奏型 | 不回到主音 = 没说完 |
| 3 | A2 | 音序略作倒影 | 五音集合 | 记忆被重新拼接 |
| 4 | Coda | 只留前三个音 + 最后的 D–E♭ | 首尾 | 让听者自己补完 |

### 4.3 和弦网格

逐小节排定，写成脚本里的常量表，不要现场即兴。

| 小节 | 和弦 |
|---|---|
| 1–8 | `E♭maj9` ×2 · `B♭/D` ×2 · `Cm9` ×2 · `A♭maj7` ×2 |
| 9–24 | `E♭maj9` `B♭/D` `Cm9` `A♭maj7` / `Fm9` `B♭13` `E♭maj9` `B♭sus4` / `A♭maj7` `Gm7` `Cm9` `Fm9` / `B♭13` `E♭maj9` `A♭maj7` `B♭sus4` |
| 25–36 | `A♭maj9` `B♭/A♭` `Gm7` `Cm9` / `Fm9` `B♭13` `E♭maj9` `Cm9` / `A♭maj7` `B♭sus4` `Gm7` `Cm9` |
| 37–48 | `Fm9` `B♭13` `E♭maj9` `Cm9` / `A♭maj9` `B♭/A♭` `Gm7` `Cm9` / **`A♭m6`** `B♭sus4` `E♭maj9` `B♭sus4` |
| 49–60 | `E♭maj9` `B♭/D` `Cm9` `A♭maj7` / `Fm9` `B♭13` `E♭maj9` `Cm9` / `A♭maj7` `Gm7` `Fm9` `B♭sus4` |
| 61–66 | `E♭maj9` `A♭maj7` `Fm9` `B♭sus4` `E♭maj9` `E♭maj9(add9)` |

五条和声规则：

- 每段 ≤4 个和弦功能；和声节奏 ≥2 拍，让旋律的呼吸被听见。
- **避免强 V–I。** 收尾用 `B♭sus4 → E♭maj9(add9)`，挂留不完全放下。
- 高点前 4 小节引入同主音的 **IVm**（`A♭m6`）：这是全曲唯一的"酸楚"，只用一次。
- 低音保持，内声部以级进移动；延伸音（9、13）负责温和摩擦，不用不协和音程硬造紧张。
- 终止式与开头的第一个和弦要对得上，否则"回到现在"这句是假的。

### 4.4 旋律事件表

旋律存成四元组列表，而不是散落在渲染代码里：

```python
# (小节偏移, 拍, 音名, 时值(拍), 力度 0–1)
THEME_A = [
    (0, 0.0, "Bb4", 1.5, .62), (0, 1.5, "Eb5", .5, .56), (0, 2.5, "G5", 1.5, .58),
    (1, 0.0, "F5", 1.5, .58), (1, 1.5, "Eb5", .5, .52), (1, 2.5, "D5", 1.5, .55),
]
```

好处：旋律可被 MIDI 导出、被 QA 脚本读取、被单独替换音色，而不必改渲染逻辑。

密度上限：主旋律 **≤8 个事件/小节**（4/4、60 BPM 的抒情曲）；琶音不计入。超过这个密度，留白就没了。

### 4.5 留白

- 句尾留 1–2 拍空白，让上一个和弦继续响。
- 每 8 小节至少一处完整休止。
- 休止不是删音符，是**提前收尾**：样本的主音在句尾用 `-5 ms` 提前释放。

## 5. 阶段 3：演奏

### 5.1 触键三层

每个音色至少三档，且**力度同时改变音量、起音、噪声、泛音**，不只是一个音量旋钮。

| 参数 | 轻触 | 中触 | 强触 |
|---|---|---|---|
| 起音时间 | 100 ms | 85 ms | 75 ms |
| 弓毛/槌击噪声 | ×0.010 | ×0.020 | ×0.030 |
| 高次泛音 | 快速阻尼 | 中 | 略多 |
| 低通截止 | 3.8 kHz | 4.1 kHz | 4.4 kHz |
| 颤音深度 | 0.11% | 0.17% | 0.23% |

（音分漂移不列在表里：样本由乐句位置函数决定，约 ±1.6 音分，与力度无关。）

### 5.2 Tempo map

速度不是常数，写成锚点表，再用线性插值 + 累积求和换算成秒。

| 拍 | BPM | 意图 |
|---|---|---|
| 0 | 58 | 开头更慢，像刚想起来 |
| 32 | 59 | 渐入 |
| 96 | 60.5 | A1 中段推进 |
| 144 | 62 | 高潮略快 |
| 192 | 60 | 回落 |
| 240 | 57 | A2 松弛 |
| 252 | 55 | Coda 前减速 |
| 264 | 51 | 结尾几乎停下 |

**实现要点**：以 0.01 拍为网格插值 BPM，再 `cumsum(60/bpm × 0.01)` 得到时间轴；所有事件用 `sec(bar, beat)` 定位。**不要用 `beat × 60 / BPM` 直接乘**——一旦有 rubato，所有段落边界都会错位。

### 5.3 微时序

成组偏移，不逐音随机：

| 位置 | 偏移 | 理由 |
|---|---|---|
| 句首 | +10~15 ms（略迟） | 像吸气之后才发声 |
| 句中 | ±7~12 ms 缓慢摆动 | 由乐句位置函数产生，非白噪声 |
| 句尾 | −5 ms（提前收） | 松弛，不拖 |
| 和弦滚奏 | 每音 +28 ms（20–35 ms 区间） | 人手不是同时按下 |
| 回声层（音乐盒） | +32 ms | 从另一个房间传来 |
| 双轨加厚 | +20 ms，音高 +0.1% | 避免相位抵消 |

### 5.4 连奏与滑音

- 判定：与上一音的间隔 **< 200 ms** 视为 legato。
- 滑音时间常数 85 ms：`f0 = prev + (f - prev) × (1 - e^(-t/0.085))`。
- 非连奏时起音先低 1.4 音分，再在 110 ms 内升到位，模拟"找准音高"的过程。

### 5.5 乐句位置函数

`phrase_pos = idx / (事件数 - 1)`，用它驱动音分漂移与颤音延迟：

```python
cents = 1.0 * sin(phrase_pos * 5.7 + .3) + 0.6 * sin(phrase_pos * 14.3 + 1.1)
```

同一函数同时喂给音高、力度包络与声像，变化才会"相关"而不是各自随机。

## 6. 阶段 4：音色

通用三层：**激励 → 共振体 → 辐射与空间**。每件乐器一张参数卡，写清"值 + 作用"。

### 6.1 毛毡钢琴（和声与影子）

| 参数 | 值 | 作用 |
|---|---|---|
| 泛音数 | 10 条，拉伸 `f·h·√(1+B h²)`，B = 0.00045 | 钢琴弦的非谐和刚性 |
| 衰减 | `τ = 2.8/(1+0.26h) × (0.65+0.55·vel)` | 高次泛音更快消失 |
| 幅度 | `1/h^1.65`，h > 5 再 ×0.55 | 毛毡/弱音踏板的暗淡 |
| 双弦失谐 | ×0.9997 与 ×1.0003 | 轻微拍频，避免电子感 |
| 槌击噪声 | 带通 550–3800 Hz，`e^(-62t)` | 起音的"触感" |
| 琴体共振 | 180 Hz +2.4 dB、560 Hz +1.4 dB | 木箱体积感 |
| 低通 | 6.0 kHz | 退到影子 |

### 6.2 加弱音器中提琴（主音）

| 参数 | 值 | 作用 |
|---|---|---|
| 泛音 | 8 条，`1/h^1.55 × e^(-0.10h)` | 弱音器让高次泛音快速衰减 |
| 衰减 | `τ = 3.2/(1+0.22h)` | 尾巴短而暗 |
| 琴体共振 | 280 +2.0 dB、680 +1.4 dB、1500 +0.6 dB | 中提琴的木质腔体 |
| 凹陷 | 3300 Hz −1.6 dB | 去掉鼻音 |
| 弓毛噪声 | 带通 280–2600 Hz，`0.010+0.020·vel` | 摩擦而非敲击 |
| 起音 | 75–100 ms 缓慢绽放 | 没有硬槌击 |
| 低通 | 3800 + 600·vel Hz，四阶 | 强奏不靠"变亮" |
| 释放 | 0.38 s | 弓离开弦 |

**关键决策**：主音从"玻璃"改为"加弱音器中提琴"时，和声、旋律、结构、情绪弧线全部不动，只换激励与模态。玻璃的 2.76 / 5.4 / 8.93 倍非谐和模态会在 2–6 kHz 留下金属余响，而弱音器中提琴是近整数泛音 + 低 Q 共振，听起来更暖、更旧、更近。

### 6.3 音乐盒（远景回声）

| 参数 | 值 |
|---|---|
| 非谐和模态 | 1 / 2.76 / 5.4 / 8.93 倍，衰减 2.4 / 0.9 / 0.45 / 0.28 s |
| 槌击 | 带通 3500–10500 Hz，`e^(-95t)` |
| 低通 | 6.8 kHz |
| 混响发送 | 长混响 0.38（全曲最高） |
| 触发 | 只在一部分音符上出现，固定滞后 32 ms |

### 6.4 弦乐组与簧风琴（中景与温度）

| 乐器 | 参数 |
|---|---|
| 大提琴 | 8 泛音 `1/h^1.28`，共振 240 / 520 Hz，低通 3.4 kHz |
| 小提琴 | 共振 380 / 950 Hz，低通 5.2 kHz，颤音 4.3 Hz |
| 弓弦包络 | 起音 0.35 s，释放 0.55 s |
| 簧风琴 | 10 泛音 `1/h^1.5`，奇次为主；低通 1.9 kHz；呼吸起伏 0.23 Hz / ±5% |

四条音色规则：

1. **力度必须联动 ≥3 个参数**（音量、噪声、泛音、截止）。
2. **高次泛音的衰减必须快于低次**，否则声音"不落地"。
3. **关掉混响做一次 solo**：还能听出材质，才算成立。
4. **不要在 2–6 kHz 留长尾**。这是"刺耳余响"和"廉价空气感"的高发区。

### 6.5 人声（如适用）

带人声的歌，人声是"第三条主音"，规则与器乐主音相同，另加五条：

| 项 | 做法 |
|---|---|
| 干声 | 近讲，短混响 <1.2 s，预延迟 8–15 ms；长混响只做尾，不糊字 |
| 气声 | 2–6 kHz 的噪声必须随乐句起伏，不能是一条恒定的"嘶" |
| 颤音 | 延迟 200–300 ms 起振，深度 0.3–0.6%，句尾略加深 |
| 齿音 | 5–8 kHz 用动态 EQ 只压齿音瞬态，不要全局去齿 |
| 和声 | 至多一条三度，比主唱低 8–12 dB，且不与主唱抢同一频段 |

**人声与器乐主音只能有一个在"前台"。** 同一段落里两条主旋律竞争，是最常见的编曲错误：副歌前让器乐主音退出，或整体降 3–6 dB 后移。

## 7. 阶段 5：工程实现

### 7.1 目录

```
<song>/
  tools/compose_<name>.py    # 唯一真源：常量、和弦、旋律、渲染、母带
  tools/export_midi.py       # 从同一真源导出 MIDI
  tools/qa_<name>.py         # 客观测量
  build/                     # 中间 wav（不入库）
  output/                    # 交付文件
```

一个工程只允许一个"真源"脚本。所有交付物（MIDI、封面文案里的时长、文档里的数值）都从它派生，否则三处数字迟早对不上。

### 7.2 常量与派生量

| 常量 | 样本值 | 说明 |
|---|---|---|
| `SR`（合成） | 32000 | 先低后高，内存减半；母带再重采样 |
| `BARS` | 66 | 段落表由它校验 |
| `TAIL` | 7.0 s | 混响与房间尾音，不占用小节 |
| `SEED` | 20261107 | 固定，保证可复现 |
| `TPQ`（MIDI） | 480 | 4 分音符 480 tick |

内存估算：`采样数 × 声道 × 4 字节`。4:34 @ 32 kHz 单条立体声 bus ≈ 70 MB；master（立体声）+ 两条单声道 send ≈ 140 MB。把 send 写成立体声就会变成 210 MB——这正是下面这些规则存在的原因。

### 7.3 渲染顺序与内存

```python
b = render_piano()          # 先渲染第一条 bus
master = new_bus()          # 再分配 master
short_send = zeros(N); long_send = zeros(N)   # 最后分配发送
```

规则：

- **先渲染最大的一条 bus，再分配 master 与 send**，峰值内存能降一个档。
- **同时存在的全长立体声缓冲 ≤2 条。** 32 kHz / 274 s 的一条 ≈ 70 MB，两条 ≈ 140 MB；多一条就可能起不来。
- 长 bus 滤波用**分块就地 `sosfilt`**（保持 `zi` 连续），不要生成新数组。
- 卷积用**单声道发送**再在 IR 内部展开立体声，省一半内存。
- 滤波器系数显式 `.astype(np.float32)`：`sosfilt` 遇到 float64 系数会输出 float64，内存直接翻倍。
- 混音加法就地做：`bus *= gain; master += bus`，不要 `master += bus * gain`（后者临时再开一条全长缓冲）。
- 每条 bus 渲完 `del` + `gc.collect()` 再进下一条；两条混响返回串行处理，加完一条就释放。

分块常数（样本实测可用）：

| 用途 | 分块 |
|---|---|
| 混响发送累加 | 1,000,000 采样 |
| 长 bus 滤波 | 500,000 采样（保留 `zi`） |
| 房间底噪生成 | 4.0 s |
| 卷积 | 整段（`oaconvolve` 自带分块 FFT） |

### 7.4 音符缓存

同一 `(音高, 力度层)` 的音色片段可复用。缓存上限 36 条，**滤波前必须清空**，否则会把已处理过的片段再处理一次。

### 7.5 数值安全

- 每个发声函数结尾做 `clickless`（首尾 1.5–4 ms 淡入淡出），防止边界爆音。
- 所有滤波器频率 `< SR/2`；除法与指数加 `max(1e-9, …)`。
- 混音总线用 `tanh` 软限幅，不用硬削波。
- 中间文件一律 float32，母带最后一步才转整型。
- 持续性噪声（房间底噪、空气声）**必须分块生成**：一次性生成 4:34 的底噪会瞬间吃掉 175 MB。

### 7.6 补丁式修改的三条规矩

这个项目的音色、母带、文档是靠 22 个"字符串替换补丁"逐次改出来的。快，但出现过两次**静默失效**：补丁没命中，脚本照常退出 0，参数其实没变。

1. **每个补丁必须断言命中次数。** `assert s.count(old) == 1`，改完 `py_compile`。
2. **打印"命中 / 未命中 / 无变化"。** 前后字符串相同就是空操作，必须报出来。
3. **一次只改一个变量，改完立刻重测。** 补丁脚本 ≤50 行；改完不跑 QA 的补丁等于没改。

改签名时要清理调用点：样本里 `pnote(ring=...)` 已不再使用 `ring`，但 5 处调用仍在计算并传入它——这类死参数不会报错，只会让人误以为它在起作用。

### 7.7 依赖

`numpy`、`scipy`（`butter` / `sosfilt` / `oaconvolve` / `wavfile`）、`mido`（MIDI）、`Pillow`（封面）。不引入采样库、不调用云端模型；所有声音由代码生成。

## 8. 阶段 6：混音

### 8.1 三级增益

事件增益 × 段落增益 × bus 增益。三级分开的好处是：改整体平衡不动段落表情，改段落表情不动单音力度。

| 段落 | 增益 |
|---|---|
| Intro | 0.92 |
| A1 | 0.95 |
| B | 0.96 |
| Climax | 1.32 |
| A2 | 0.90 |
| Coda | 0.74 |

注意：climax 的段落增益比 B 高约 2.8 dB，但**实测 RMS 只高 1.3 dB**——因为高潮的编制密度、音区与和声承担了大部分"高点"，增益只是辅助。段落增益不是响度旋钮。

**减法之后要补电平。** A2 撤掉弦乐与簧风琴后，主音段增益从 0.60 提到 0.66、钢琴影子从 0.30 提到 0.42（+2.9 dB）——不是"想更响"，而是少了三层中景之后，不补就会从"安静"变成"空"。这是样本里最容易被忽略的一次混音决定。

### 8.2 通道表

| bus | 增益 | 短混响发送 | 长混响发送 | 声像 | 滤波 |
|---|---|---|---|---|---|
| 毛毡钢琴 | 0.74 | 0.18 | 0.05 | −0.12 | 低切 42 Hz；低架 105 Hz −1.2 dB；330 Hz +0.8 dB |
| 中提琴主音 | 0.58 | 0.26 | 0.10 | −0.08 | 120–4200 Hz；3200 Hz −1.2 dB |
| 音乐盒 | 0.32 | 0.08 | **0.38** | +0.34 | 长混响推远 |
| 弦乐 | 0.34 | 0.30 | 0 | ±0.2 / +0.25 | 低通 5.4 kHz |
| 簧风琴 | 0.24 | 0.24 | 0 | −0.3 → +0.3 | 低通 2.1 kHz |
| 效果层 | 0.20 | 0.08 | 0.18 | +0.4 | 低通 3.5 kHz |

### 8.3 空间

| 空间 | 参数 |
|---|---|
| 短混响 | IR 1.9 s，预延迟 12 ms，170–4700 Hz 带通，返回 ×0.38 |
| 长混响 | IR 4.2 s，预延迟 28 ms，210–4200 Hz 带通，返回 ×0.34 |
| 早期反射 | 11 / 19 / 31 / 47 / 73 ms，增益 0.50 / 0.30 / 0.20 / 0.12 / 0.08 |
| IR 衰减 | `noise × e^(-6t/T60)`，左右声道独立噪声 |
| 房间声 | 噪声 120–6500 Hz，阵风 0.017 Hz 与 0.006 Hz 两层，约 −34 dBFS |

**距离感不等于混响量**：主音近景靠干声比例，音乐盒的远靠"长混响 + 高频被吸收 + 32 ms 滞后"三件事一起做。

### 8.4 混音验收

- 主音干声占比 >60%（样本钢琴干声比例高，关掉混响仍有琴槌与琴体）。
- 立体声相关度 0.85–0.95（样本 0.94）；>0.97 说明宽度全靠混响，声源本身没展开。
- 2–4 kHz 与 4–8 kHz 的能量不要靠激励器硬拉；暖色是"少一点高频"，不是"多一层空气"。

## 9. 阶段 7：母带

### 9.1 目标值

| 指标 | 样本实测 | 允许区间 | 越界动作 |
|---|---|---|---|
| 综合响度 | −15.0 LUFS | −16 ~ −14 LUFS | 调 bus 增益，不用限幅硬推 |
| 真峰 | −2.5 dBFS | ≤ −1.0 dBFS | 降归一化电平 |
| 响度范围 | 10.5 LU | 8–12 LU | 压缩段落差，不是压单音 |
| 脚本内归一化峰值 | 0.82（≈ −1.7 dBFS） | ≤ 0.85 | 给编码与重采样留余量 |
| 立体声相关 | 0.94 | 0.85–0.95 | 检查声像与混响 |
| 频谱重心 | 412 Hz | 300–800 Hz（先瞄准 400–600） | 检查低通与高架 |

### 9.2 处理链

顺序固定，理由写在右边：

| # | 处理 | 参数 | 理由 |
|---|---|---|---|
| 1 | 低架 | 85 Hz +0.6 dB，Q 0.7 | 补一点房间体积，不做"咚" |
| 2 | 峰值 EQ | 330 Hz −0.6 dB，Q 0.9 | 去箱音 |
| 3 | 峰值 EQ | 2600 Hz −0.4 dB，Q 1.0 | 去一点"硬" |
| 4 | 高架 | 5600 Hz −0.8 dB，Q 0.7 | 刻意的暖色，不造假空气 |
| 5 | 高通 | 35 Hz，二阶 | 去直流与次声 |
| 6 | 软限幅 | `tanh(x/peak × 1.05)`，归一化 | 只做保险，不做响度 |
| 7 | 淡入 | 2.5 s，`^1.4` | 从房间声里浮现 |
| 8 | 淡出 | 11 s，`^1.25` | 交给混响尾音 |
| 9 | 归一化 | 峰值 0.82（≈ −1.7 dBFS） | 脚本内参考电平 |
| 10 | 交付微调 | 按实测真峰整体衰减到 −2.5 dBFS | 有损编码需要余量 |

四条规则：

- **EQ 在限幅之前。** 限幅后再提亮，等于把失真一起放大。
- **限幅只做保险。** 若需要 3 dB 以上增益衰减才有响度，问题在编曲密度，不在母带。
- **相邻段落的 RMS 差 ≤1.5 dB（B → Climax）。** 样本 Intro −26.0 / A1 −17.4 / B −16.4 / Climax −15.1 / A2 −18.6 / Coda −25.4；climax 只比 B 高 1.3 dB。首尾段可以更轻，这不是"不平均"。
- **0.82 与 −2.5 dBFS 不要混用。** 0.82 是脚本内的归一化参考（≈ −1.7 dBFS）；真峰 −2.5 dBFS 是重采样后再整体衰减的最终测量值。真峰不可能低于采样峰值，所以"−2.5"意味着最后又降了约 0.8 dB，不是把 0.82 当成了 −2.5。

### 9.3 导出

合成在 32 kHz，母带重采样到 **48 kHz**（`scipy.signal.resample_poly(x, 3, 2)`，或外部工具），写 **24-bit** WAV。重采样放在淡入淡出与归一化之前，避免重采样后的峰值漂移。

## 10. 阶段 8：验证

### 10.1 四项测量

每次改完必须重跑，不要凭记忆。脚本可用 `scipy` + `numpy` 直接写：

```python
import numpy as np
from scipy.io import wavfile
from scipy.signal import welch

SR, x = wavfile.read("build/master_48k.wav")
x = x.astype(np.float32)
mono = x.mean(axis=1)

def db(seg): return 20 * np.log10(np.sqrt(np.mean(seg ** 2)) + 1e-12)

print("dur", len(mono) / SR, "peak", float(np.max(np.abs(x))), "rms", db(mono))

f, P = welch(mono, fs=SR, nperseg=8192)
tot = np.trapezoid(P, f)
for lo, hi in [(20,60),(60,120),(120,250),(250,500),(500,1000),
               (1000,2000),(2000,4000),(4000,8000),(8000,16000)]:
    m = (f >= lo) & (f < hi)
    print(f"{lo:5d}-{hi:5d}", round(10 * np.log10(np.trapezoid(P[m], f[m]) / tot), 1), "dB")

print("centroid", round(float(np.sum(f * P) / np.sum(P)), 1))
print("L/R corr", round(float(np.corrcoef(x[:, 0], x[:, 1])[0, 1]), 3))
```

（`np.trapezoid` 需 NumPy ≥ 2.0；旧版用 `np.trapz`。LUFS 与真峰用 `ffmpeg -af ebur128` 或母带插件测，**不要用 RMS 冒充 LUFS**。）

分段 RMS 用同一时间映射，按段落边界切片：

```python
for name, a, b in [("intro",0,8),("A1",8,24),("B",24,36),
                   ("climax",36,48),("A2",48,60),("coda",60,66)]:
    seg = mono[int(sec(a) * SR):int(sec(b) * SR)]
    print(name, round(db(seg), 1))
```

（`sec()` 从真源脚本导入：`from compose_<name> import sec`。）

把这些输出存成 `qa_report.txt`，**文档里的每个数字都从这里复制**。样本曾出现文档写的分段 RMS 与 wav 实测差 1–2 dB（重测后 Intro −24.5→−25.3、重心 553→454 Hz），原因就是手抄了旧版本的数字。

每次改版都留一条版本记录，数字会告诉你改动是否真的发生：

| 版本 | 主音 | 频谱重心 | 2–4 kHz | 钢琴低通 | 真峰 / LRA |
|---|---|---|---|---|---|
| v1 | 毛毡钢琴 | 553 Hz | −19.6 dB | 7.2 kHz | −3.1 dBFS / 9.2 LU |
| v2 | 弓弦玻璃 | 454 Hz | −21.8 dB | 6.6 kHz | −2.9 dBFS / 10.7 LU |
| v3 | 加弱音器中提琴 | 412 Hz | −22.9 dB | 6.0 kHz | −2.5 dBFS / 10.5 LU |

**单音 QA 不能替代母带测量。** 单音测试只回答"这件音色的重心与频段分布对不对"，不含总线 EQ、混响与母带链；交付数字必须来自成品 wav。

### 10.2 阈值

见 9.1 表。三条最容易越界：真峰（重采样后 +0.5~1 dB）、分段 RMS 差（>2 dB 说明高点靠音量）、频谱重心（<300 Hz 会闷，>1 kHz 会薄）。

### 10.3 四问自检

1. **删掉音色后，动机还成立吗？** 成立才算写好了。
2. **高潮是否过度？** 没有鼓组、动态只高 1.3 dB，高点靠音区与和声才算数。
3. **怀旧是否只靠噪声和低通？** 若动机重复、句尾未解决、IVm 与挂留都不存在，那就是滤镜，不是作品。
4. **空间是否掩盖主体？** 关掉混响，钢琴的槌、琴体、踏板余振应当还在。

### 10.4 缺陷速查

见附录 B（缺陷 → 修复速查）。22 个真实修补按主题归类，几乎覆盖了这类项目的全部常见故障。

### 10.5 诚实边界

**测量不等于听感。** 上面所有数字只能证明"没有削波、没有直流、动态与频谱符合设计"，不能证明"情感表达成功""音色自然""混音平衡"。没有做盲听，就不要在文档里写"听感已验证"。

### 11.3 MIDI 规格

MIDI 是**结构草图**，不是演奏复刻。写清这一点，比多导一轨更有价值。

| 项 | 值 |
|---|---|
| 格式 | Type 1，TPQ 480（1920 tick/小节），5 轨 = 1 meta + 4 音符轨 |
| 速度 | 固定 60 BPM（`set_tempo` = 1 000 000 µs）；无 tempo map |
| 拍号 / 调号 | 4/4 / E♭（3 降） |
| 标记 | 6 条 marker：`intro @ bar 0` … `coda @ bar 60`（小节号从 0 计） |
| 轨道 | 钢琴旋律（ch0, prog 0）· 钢琴和声（ch1, prog 0）· 音乐盒（ch2, prog 10）· 弦乐（ch3, prog 48） |
| 力度映射 | 旋律 `int(vel×100)` → 实测 32–64；和声固定 45；音乐盒 `int(max(.2,vel)×70)` → 26–44；弦乐 55 |
| 滚奏 | 和弦每音 +25 tick（52 ms）；收尾提前 20–30 tick |

**长度差是设计结果，不是 bug。** 66 小节 × 4 拍 @ 60 BPM = 264 s，而音频主体 267 s + 7 s 尾音 = 274 s：MIDI 比音频短约 10 s，因为它既没有 rubato，也没有房间尾音。文档里必须写明。

**MIDI 里也没有力度弧线。** 段落增益（climax 1.32）不会进入 MIDI，高潮在 MIDI 里并不比 B 段更强；同样没有 CC、延音踏板、pitch bend。它是结构稿，表情在音频里——需要表情就另做一版带 CC 的演奏稿，不要指望这一份。

音频里的 58–62 弹性速度与逐音微时序**不会**进入 MIDI。文档里必须写明，否则使用者会以为两者对不上是 bug。

### 11.5 文档

两份，内容同源：

- **README**：规格表、音色、情绪设计、交付清单、制作规格、版本说明。
- **创作手记**：4 页 A4——封面 / 情绪弧线与结构 / 动机与和声 / 演奏·音色·空间与验证。

**排版实现（样本）。** 手记不是用 PDF 库逐行绘制，而是"HTML → 打印"：

- 源：一份自包含 HTML（CSS 内嵌），一份文件对应一本册子。
- 渲染：Playwright 驱动本机 Chrome headless，`page.pdf({format:'A4', printBackground:true, margin:0, preferCSSPageSize:true})`。
- 版式：A4 210×297 mm；`.page` 定高 + `page-break-after:always`；正文 8.4 pt / 1.7 行高；标题 23–36 pt 中宋；纸底 `#f5ecdd`，金色 `#d8ad72`。
- 校验：页数必须恰好 4，MediaBox ≈ 595×842 pt；`overflow:hidden` 会**静默裁切**，必须逐页目检页底有没有被切掉一行。

**单一事实源。** 时长、主音名、乐器清单、钢琴低通截止、LUFS/TP/LRA、六段 RMS——这六类事实同时出现在封面、PDF、README、手记四处。把它们放进一个 `FACTS` 常量，由生成脚本读取：

```python
FACTS = dict(duration="4:34", lead="MUTED VIOLA",
             instruments="MUTED VIOLA / FELT PIANO / MUSIC BOX",
             piano_lp=6000, lufs=-15.0, tp=-2.5, lra=10.5)
```

样本项目没这么做，代价是：同一个低通截止被写成 `7.2 → 6.6 → 6.0 kHz` 三个值，主音名被改两次（`STRINGS → BOWED GLASS → MUTED VIOLA`），指标被重写两遍——同一事实手工同步了 7 次。

规则：**测量 → `qa_report` → `FACTS` → 四处输出**，单向流动；改版时先改 `FACTS` 再重新生成，不手改文案。

## 附录 B：缺陷 → 修复速查

> 来自样本项目 44 个工具脚本中的 22 个逐次修补补丁。左列是症状，右列是已验证的处理方式；"教训"一列是可以直接搬走的规则。

### B.1 内存与性能

| 症状 | 修复 | 教训 |
|---|---|---|
| 渲染到一半 MemoryError | 合成 48 → 32 kHz；先渲首 bus 再分配 master/sends；send 改单声道 | 同时存在的全长立体声缓冲 ≤2 条（≈140 MB） |
| 滤波器一跑内存翻倍 | `butter(...).astype(np.float32)`；手搓 biquad 也 `dtype=np.float32` | 32-bit 管线里系数也要 float32，否则 `sosfilt` 输出 float64 |
| 每条 bus 滤波产生新数组 | 统一 `filt_bus`：2 阶 SOS + `axis=1` + 50 万采样分块并保留 `zi` | 长信号就地处理，不要 `bus = filt(bus)` |
| 混音加法又开一条全长缓冲 | `add()` 里就地 `bus *= gain; master += bus` | 就地运算，别 `master += bus * gain` |
| 房间底噪一次性吃掉 175 MB | 4 s 分块生成、直写 master，不走 bus 通道；补 12 s 收尾淡出 | 长噪声必须分块，O(N) → O(chunk)（175 MB → 约 3 MB） |
| 立体声卷积占两倍 | 发送先下混单声道，IR 内部再展开 | 混响不需要两路独立发送 |
| 缓存键含 `ring`、且无上限 | 键改 `(音高, 3 档力度)`；`ring` 由音区推导；上限 36 条 | 缓存键只放真正影响音色的维度 |

### B.2 动态与段落

| 症状 | 修复 | 教训 |
|---|---|---|
| 全曲一个响度 | 段增益 `.78/.92/1.0/1.08` → `.92/.95/.98/1.18` → climax 1.32、B 0.96 | 段差 0.67 → 1.62 → 2.77 dB；实测 RMS 只差 1.3 dB |
| 高潮撑不住 | 每 2 小节加根音低八度；弦乐改用和弦最后一音的高八度 | 先加内容，再动电平 |
| 撤掉弦乐后主音发空 | 主音段增益 A2 0.50→0.64、coda 0.38→0.56；钢琴影子 A1 0.30 / A2 0.42 / coda 0.44 | 减法后给主音补 1–3 dB，否则是"空"不是"安静" |
| 段落边界突兀 | 反向钢琴 swell（段前 2.2 s，低通 3.5 kHz） | 用渐入的尾巴转场，不用鼓 fill |

### B.3 音色与频率

| 症状 | 修复 | 教训 |
|---|---|---|
| 整体发闷、小喇叭听不见 | 钢琴低通 4.2→6.0 kHz；槌击带在 550–3800 与 700–5600 Hz 两版之间调过 | 提"激励的高频"，单次 ≤1 dB |
| 提亮过冲 | 5.6 kHz 高架在 26 分钟里走了 `−1.1 → +1.6 → +2.0 → +1.2 → −0.8` dB 五个值 | 亮度必须写成一条可测的目标曲线，否则会在母带上横跳 |
| 主音金属余响 | 玻璃的 2.76/5.4/8.93 倍非谐和 → 弱音器中提琴 280/680/1500 Hz 共振 + 3.8–4.4 kHz 四阶低通 | 2–6 kHz 长尾是"廉价感"来源 |
| 中低频箱音 | 320 Hz +1.0 → 330 Hz −0.6；2600 Hz +1.0 → −0.4 | 中低频加容易"糊"，减才清 |
| 音乐盒太近、太亮 | 低通 6.8 kHz + 长混响 0.38 + 滞后 32 ms | 距离 = 高频吸收 + 混响 + 时间差 |
| 弦乐糊住主音 | 弦乐 bus 0.34、高切 5.4 kHz、A2 全撤 | 中景要么让路，要么退场 |

### B.4 时序与量化

| 症状 | 修复 | 教训 |
|---|---|---|
| 用全局 BPM 常量算时值 | `beat_len = (sec(bar+1) − sec(bar)) / 4` | 51–62 BPM 下误差 −3.3% ~ +17.6% |
| MIDI 网格感重 | 音频走 tempo map + 微时序；MIDI 只做结构 | 交付 MIDI 与交付音频是两件产品 |
| 和弦像机器弹的 | 滚奏 25–28 ms；句首 +15 ms；句尾 −5 ms | 微时序成组，不逐音随机 |
| 段落边界与拍点错位 | 统一 `sec(bar, beat)`，禁止 `beat*60/BPM` | rubato 一旦存在，乘除法都是错的 |

### B.5 缓存、状态与代码

| 症状 | 修复 | 教训 |
|---|---|---|
| 重复的函数头（语法错误） | 删除重复的 `def render_piano()` | 字符串替换补丁必须 `py_compile` |
| 补丁静默失效 | master EQ 补丁的锚点已被前一个补丁改写 → 至今仍是 out-of-place EQ；高架补丁锚点不匹配 → 最终 −0.8 而非 −0.2 | 每个补丁 `assert count == 1`，打印"命中 / 未命中 / 无变化" |
| 7 条替换里 3 条前后字符串相同 | 记录 before/after | 空操作必须报出来 |
| 死参数 | `pnote(ring=...)` 已忽略 `ring`，5 处调用仍在计算 | 改签名要清调用点 |

### B.6 交付物与文档一致性

| 症状 | 修复 | 教训 |
|---|---|---|
| 封面时长是占位符 `4:2?` | 从真源重算 4:34 | 封面数值从同一真源取 |
| 封面乐器栏写错 | STRINGS → BOWED GLASS → MUTED VIOLA，改三次才对 | 换主音必须同步封面文案 |
| 文档频率与实现不符 | 钢琴低通 7.2 → 6.6 → 6.0 kHz；混响低通文档写 5 kHz、代码 4.2 kHz；玻璃模态整段改写成弱音器中提琴 | 音色改了要重写整段，不只改数字 |
| 摘要图压住标题字 | 裁切改为 (1300, 250, 2800, 1750) | 生成后必须目检字形 |
| 六段 RMS 与文档差 1–2 dB | qa 重测（Intro −24.5→−25.3，重心 553→454 Hz） | 数字由 qa 脚本生成并注入文档 |
| 母带写 int16 后再处理 | 全程 float32 | 位深损失不可逆 |

### B.7 流程教训

- **22 个补丁在 26 分钟内完成，留下两处静默失效。** 改参数很快，确认它真的改了很慢——速度不能替代断言。
- **每个补丁 ≤50 行，只改一件事，改完立刻重测。** 否则无法判断是哪一处生效。
- **参数会来回摆动。** 5.6 kHz 高架在 26 分钟里走了五个值（−1.1 → +1.6 → +2.0 → +1.2 → −0.8）；每次动手前先写"当前值、目标值、验收指标"。
- **先回音色层。** 母带 EQ 修不好"金属余响""箱音""糊"，这些是激励、模态与低通的问题。
- **数字单向流入交付物。** 测量 → `qa_report.txt` → README / 手记 / 封面；反向手抄一定会错。
